# Changelog

## 1.0.0

- Added context-menu import from Burp HTTP history.
- Added context-menu import from Burp message editors such as Repeater.
- Added existing Postman collection and folder selection.
- Added editable request names.
- Added global Content-Type and Content-Length import controls.
- Added request-body conversion for common content types.
- Added local collection backups before updates.
- Added Gradle Wrapper-based cross-platform builds.
