# Security Policy

## Reporting a vulnerability

Please do not publish unpatched security vulnerabilities in a public GitHub issue.

Instead, use GitHub's private vulnerability reporting/security advisory feature if it is enabled for the repository, or contact the repository maintainer privately.

## API keys

Never include a Postman API key in source code, screenshots, commit messages, or public issues.

If an API key is accidentally committed or exposed, revoke/rotate it in Postman immediately.
